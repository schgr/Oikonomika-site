# Οικονομικά — ιστοσελίδα παρουσίασης

Δημόσια, responsive ιστοσελίδα παρουσίασης της Android εφαρμογής **Οικονομικά**.

## Δημοσίευση

GitHub Pages: **Settings → Pages → Deploy from a branch → main → /(root)**.

Μετά την ενεργοποίηση, η αναμενόμενη διεύθυνση είναι:
https://schgr.github.io/Oikonomika-site/

Η ιστοσελίδα λειτουργεί ως στατικό `index.html`, χωρίς εξωτερικές εξαρτήσεις και χωρίς συλλογή δεδομένων.

## APK

Το APK **δεν περιλαμβάνεται ακόμη στο repository**. Η ενότητα λήψης παραμένει σκόπιμα ανενεργή. Πριν από την κυκλοφορία, απαιτείται έλεγχος της τελικής έκδοσης και ανάρτηση του APK ως GitHub Release asset. Μην ανεβάζετε προσωπικά τραπεζικά statements ή εφεδρικά αντίγραφα δεδομένων.

## Σημείωση

Τα ποσά και τα γραφήματα της σελίδας είναι φανταστικά. Η σελίδα δεν είναι η λειτουργική Android εφαρμογή και δεν παρέχει πραγματική διασύνδεση με τράπεζες.
